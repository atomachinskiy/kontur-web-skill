# Шрифты Lab Grotesque

Файлы `LabGrotesque-{Regular,Medium,Bold}.woff2` в репозиторий не выкладываются:
шрифт лицензирован Контуром и распространяется только внутри компании.

Возьмите woff2 из внутреннего источника (бренд-портал или дизайн-система) и положите
в эту папку. Fallback до установки: Arial (прописан в `typography-offline.css`).
