# kontur-web — скилл веб-интерфейсов в каноне Контура

Скилл для Claude Code (и совместимых агентов): собирать веб-страницы и продукты
НЕ «в стиле Контура», а на реальных токенах и правилах дизайн-системы.

Внутри: 319 семантических цветовых токенов (`foundation/colors.css`), типографика
Lab Grotesque (`foundation/typography-offline.css`), 570 иконок, эталоны блоков
(`product/`, `landing/`, `blocks/`), правила поведения интерфейса
(`reference/ux-behavior.md`) и SKILL.md как входная точка для агента.

## Установка

```bash
git clone git@github.com:atomachinskiy/kontur-web-skill.git ~/.claude/skills/kontur-web
```

Шрифты добавьте отдельно: см. `foundation/fonts/README.md` (лицензия Контура).

## Использование

Агент подхватывает скилл автоматически. Проверка: попросите собрать страницу —
в ней должны появиться `--k-color-*` токены, а не произвольные цвета.

Этим паком собрана платформа «Контур · ИИ в УМ» (kontur.ideafromai.ru).

⚠️ Материалы дизайн-системы Контура — внутренние. Репозиторий приватный;
публикация наружу только после согласования с Контуром.
